## 2. 三个 bug 的实证与修复

### 2.1 打印按钮零卡片（P0）

- **现象**：点「打印本页卡片」→ 打印输出里没有任何人物卡。
- **证据**：`printCards()` 用 `$("card-grid")`（getElementById），而 `renderCharacters()`
  （app.js:631）产出的是 `class='card-grid'`，且按核心/主要/次要**分段各一个** grid。
  id 选择器恒返回 null，旧代码 `if (grid)` 静默跳过克隆。
- **修复**：改取 `#view-characters .poke-card` 全量卡片（与屏幕所见一致，默认核心+主要）。
- **验证**：`src/probe_print_cards.js`（第 5 个固化探针）——天才 42/42、废土 90/90，
  `prints=1`、`body.printing-cards` 生效，双书 PROBE-OK。

### 2.2 打印作用域 69 页（P0）

- **现象**：任何打印途径（含打印按钮）都会输出全部 11 个视图。
- **证据**：`--print-to-pdf` 实测 69 页 / 10.8MB；`@media print` 里 `.view { display: block !important }`，
  且 CSS 无 `#print-area` 规则（克隆出的卡片区无样式）。
- **修复**：按钮点击时给 body 加 `printing-cards` 类，`@media print` 下隐藏 `#app`，
  只输出 `#print-area` 卡片区；直接 Ctrl+P 不加类，**保留完整手册模式**（两种用法都留住）。
  未进人物视图时 toast 拦截。`afterprint` + 30s 兜底清理类名。
- **验证**：同上探针（`cls=[printing-cards]`、`prints=1`）。

### 2.3 主题命名与持久化（P1）

- **现象**：按钮在 `ink`/`xuan` 间切换——`ink` 是暗色（墨玉），`xuan` 无任何 CSS 规则、
  靠 :root 兜底变亮色。功能可用但命名反直觉；刷新即丢；不跟随系统偏好。
- **修复**：
  - CSS：`:root` 保持亮色默认；新增显式 `body[data-theme="light"]`（与 :root 同值，
    三态分明不再隐式兜底）；`body[data-theme="ink"]` → `body[data-theme="dark"]`，
    暗色顺带补 `--red/--green` 覆盖（此前回落亮色值，暗底发闷）并把 `--ink-3`
    从 #6e6a60 调深到 #8f8b80（暗底对比度）。
  - JS：`loadTheme()`（localStorage → 系统偏好 → light）+ `applyTheme()`；
    按钮文案随状态变为「墨玉深色/素纸亮色」并带 title。
  - 模板：`<body>` 后内联一段主题初始化，**首绘前定主题**，消除亮→暗闪烁。
- **验证**：DOM 走查（`<body data-theme="dark">`、按钮 title「当前：墨玉深色」）；
  暗色截图 9 张（总览/人物/关系/阶段/学科视角/地图/事件 + 复核 2 张）目检无一处不可读。

**v3.7 实测到的两个无头环境限制**（写入探针注释，后续勿判为应用 bug）：
1. `--dump-dom` 下程序化 `window.scrollTo` 只改 `scrollY`、**不派发 scroll 事件**（实测 `fired=0`，无渲染帧）；
