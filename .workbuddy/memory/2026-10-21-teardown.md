## v3.23 · 仓库 CochraneK/ming 改名为 CochraneK/book-meal

用户提出改名，选了全小写 `book-meal`（我建议的写法，理由是 Pages URL 大小写敏感）。

**两个经查证的硬事实（重要，以后任何改名决策都要先讲）：**
1. GitHub 官方文档明确：重命名仓库时 "all existing information, **with the exception of
   project site URLs**, is automatically redirected"。→ **Pages 站点旧 URL 会直接 404，不重定向**；
   但仓库页 `github.com/OWNER/旧名` 会 200 跳转，git clone/fetch/push 也继续走重定向
   （官方仍建议 `git remote set-url`）。
2. **GitHub Pages URL 大小写敏感**：仓库叫 `Book-Meal` 就必须访问 `…/Book-Meal/`，
   写成小写即 404（社区多个案例佐证）。故建议仓库名一律全小写。
   官方给出的根本解法是**给 Pages 绑自定义域名**——那样仓库随便改名、URL 不变。

**改名执行**：`gh repo rename book-meal --repo CochraneK/ming -y` → `git remote set-url` → push。
改名瞬间 Pages 状态短暂 `errored`，约 20 秒后自动转 `built`（部署 run 重跑一次即成功）。
