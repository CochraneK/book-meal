## 口径与纪律

- 数据来源：**只有书本抽取结果** `data/data.json`，不含 Web 查证、不含记忆推断。
- 入选条件：`lat` 或 `lng` 为空。按 `data/data.json` **原始抽取口径**：
  全库 563 个地点，已定位 533 个，**待考 30 个**。
- 口径差异：README / 报告里写的「583 个地点 · 553 已定位」是
  `generate_report.build_scope('full')` 补入衍生地点后的**展示口径**；
  两种口径差额 20 个均已定位，因此待考数同为 30。本表只用原始抽取口径，
  避免把衍生记录混进人工考据队列。
- 表中「出处章节」是原书分部章序 key（`p<部>-c<章序>`），用于回书核对；
  章节正文按版权红线不入库、也不写进本文件。
- **本表不填任何坐标**。对「圣地巡礼」而言错误坐标比留空更有害；
  考据结论须另行标注来源层级（书本抽取 / 记忆 / Web）后才可回填 `geo_annotations.json`。
- 排序口径：按书中提及章数降序（冷门地点优先），同频按地名排序。
- 「书中提及形式」来自 `mentioned_as`，抽取时偶尔会混入上下文短语，
  **不全是严谨别名**，仅作回书检索线索，不据此推断地望。
