# Book-Meal 统一平台方向（2026-11-12）

目标：同一本书，多种入口。拆书、知识图谱、学科分析、论文展示、人生模拟、Agent 社会演化与政策反事实实验共享一本书的证据和世界状态，而不是六个重复数据库。

## 统一六层

1. Input：合法 PDF / EPUB / TXT → 解析、分章、记录版本和授权；原著全文与源输入只在私有环境使用。
2. Evidence：书、版本、章、段、偏移、抽取证据、置信度、人工修改记录；可以回源核对，但不能公开完整原文。
3. World：稳定 ID 的人物、机构、地点、事件、关系、资源、制度、时间有效区间；facts（原著事实）与 hypotheses（建模假设）分离。
4. Knowledge：剧情概述、人物卡、时间线、图谱、地理、跨学科洞察与经过引用核验的研究报告。
5. Simulation：世界快照、规则/LLM Agent、干预参数、随机种子、行动轨迹、结局指标；不可向第 n 章角色泄露 n 章以后信息。
6. Presentation：书库门户 → 故事、人物、世界、研究、推演；各书显示有数据支持的模块；移动端与离线优先。

## 工程原则

- 统一数据契约，不强制每本书长同样的 UI。
- 现有 ming、teardown、sanggan 系统先通过 adapter 共存，验收后渐进替换，严禁推倒重来。
- 书目状态：planned → ingesting → extracted → validated → published；不得把计划中的书目写成已有数据成果。
- 研究证据按 BOOK（原著）、INFER（推断）、EXT（外部资料）、SIM（模拟）标注。
- 多学科报告可以自动起草；统计数字、来源与参考文献需要核验。未达科研标准的产物叫研究笔记，不冒称论文。
- 公共仓库不得存储版权原文、私人研究资料、账号密钥或无意公开的工作日志。

## 里程碑与验收

M0 新书建档：平凡的世界建立 manifest + 建档页；总量只统计已抽取书；自动门户/导航/CI 正常。

M1 标准世界数据：建立 canonical-world schema 与 sanggan、teardown 两种适配器；人物/事件/关系有 ID、来源和时间范围；书籍独有信息不能丢。

M2 全自动导入：投入有权使用的文本 → 分章 → 逐章抽取 → 实体消歧 → 质量审计 → 叙事/图谱/学科初稿 → 预览 → 审核发布。支持断点续跑、成本上限、失败恢复、人工复核队列。

M3 暖水屯实验基准：从原著的明确节点克隆同一初始世界，分别改变经济、人口、制度和关键人物决策参数。保留决策日志与影响路径；比较规则 Agent、LLM Agent；多次复现、设定对照，并明确模拟结果不代表历史事实。

## 平凡的世界未来研究方向

三部曲中的城乡迁移、家庭资源、代际教育机会、劳动市场、乡镇经济和社会流动都可成为候选模拟变量，但具体参数与人物性格必须在原文抽取和证据核验之后再定。

## 不做

不把大型 BookWorld / Mesa 框架整份 Fork 进来；先确定世界格式与适配接口。不发布受版权保护的原文，不把伪造的人物/事件/引文/论文包装为自动化成果。

## 构建

新增 books 下的目录和 manifest 后，当前 refresh-index 工作流可自动重建门户、README 和所有书籍的导航条。发布后必须再核验最终 CI、GitHub Pages 与新书链接。
