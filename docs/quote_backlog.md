## 口径与纪律

- 语录已收录 **73 人**，实体表共 1231 人。本表列出覆盖章节最多、
  仍无语录、且尚未登记结论的 **Top 20**（滚动队列，不是固定名单）。
- 入选口径：`characters` 按提及章数降序（单键稳定排序，与 `--stats` 完全一致），
  排除已收录者，再排除 `data/quote_backlog_status.json` 里已登记结论者。
- **自动抽取归属不可靠**：2026-11-05 实测 15 条自动候选里 13 条把
  「A 对 B 说：…」误归到了 B 名下。本表因此**不提供任何自动候选原话**。
- **本表不写原文片段**：原书 TXT 与章节正文按版权红线不入库，只列聚合工件的
  元数据与出处章节 key（`p<部>-c<章序>`）供回书检索。
- **不推断说话人**：必须回原书确认「引号内原话 + 说话人 + 说话场景」三者一致；
  写进 `character_quotes.json` 后还要过 `src/verify_quotes.py` 的原文命中门禁。
- 状态登记在 `data/quote_backlog_status.json`；**未登记即视为待核对**。
  登记后该人退出队列、下一名自动补位，所以「确实没有合适台词」也能销账。

## 建议核验路径（方法论，不是语录结论）

- 优先找「人物名 + 说道 / 答道 / 喝道 / 曰 / 说」**直接前缀**的引号内原话；
- 排除「A 对 B 说：…」这类句式里 B 被误当成说话人的情况，也排除叙述者转述；
- 诗句、遗言、民间歌谣本来就没有「某某说道」前缀，需另找归属证据
  （谁写的、谁引的、上下文主语是谁），找不到就登记「归属存疑」；
- 确认原句后可跑 `python src/verify_quotes.py --strict-attribution`
  查看引号前 90 字的前缀证据，但最终仍以人工读上下文为准；
- 收录时用实体表**正名**作 key，别用别名；0 原文命中即弃用。

## 完成后怎么回填

1. 找到原话 + 说话人 → 写进 `data/character_quotes.json`
   （key 必须是实体表正名）；
2. **无论是否入库**，都在 `data/quote_backlog_status.json` 的 `entries` 里
   登记 `{status, note}`，否则同一个人会一直占着队列名额；
3. 跑 `python src/verify_quotes.py`（本机有原著 TXT 时逐条校验原文命中）；
4. 跑 `python src/build_quote_backlog.py` 重生成队列，
   README 的语录人数由 `src/sync_readme.py` 同步。
