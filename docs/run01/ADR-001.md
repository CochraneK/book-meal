# ADR-001 · 统一平台先统一契约，而不是物理合仓

状态：Proposed / Run 01（2026-11-13），待 PR 审核。范围：仅 Book-Meal 内可逆新增文件。

## 决策

- Book-Meal 是唯一书库产品入口；一本书一个顶层 World，小说内部允许嵌套子世界。
- **人物语义以 AI-Persona Human Ontology v2 为权威**；本仓只定义互操作 envelope，不增加另一套心理学分类。
- 各书独立私有/公共 source 保留；source → adapter → ephemeral World Contract 只读单向投影；不要求旧站切换数据源。
- 人物、事件、关系与证据统一稳定 ID、章位引用、来源类型、时间范围。缺失和推断不等于观测事实。
- 任何未登记的人物或类型不明端点保留为 unresolved entity，不计入 person 数，不添加虚构心理。
- 书籍特殊字段放 extensions；格式化、权限和科学效度由专门消费者决定。
- 现阶段不引入 BookWorld / TinyTroupe / Mesa / Concordia 依赖，不修改八个参考仓库。

## 被放弃的备选

1. 把所有仓库整份拷贝到 Book-Meal：破坏私有来源、重复真源、依赖过大。
2. 所有书籍各自开一套本体：后续无法共享模拟器与分析器。
3. 将人物画像直接视为可预测的 Agent：混淆观测、推断与行为假设。
4. 直接把 sanggan 导出 JSON 提交公共 Git：可能侵犯版权并造成敏感资料泄露。

## 设计限制

- v0.1 不尝试定义全面的社会规则、心智状态、仿真效度或论文标准。
- v0.1 不保存私有 kernel payload；只提供授权本地环境中的 kernel_path 指针。
- Ming 某些关系目标属于机构/政权或未登记对象；转成待复核实体。
- canonical ID 是稳定的来源键哈希，不代表同名跨书的人是同一个人。
- PDF/TXT 原文与人工研究日志不进入输出。
- 数据转换只保存核心跨书投影；原书特殊完整资产仍在源文件。保留在 extensions 的是高价值少量字段或引用，不是逐字无损复制。

## 验收

1. 旧构建仍从原来的 data 读取，输出不退化。
2. CI 能用已公开的 Ming 聚合数据执行完整只读转换。
3. Private Sanggan 使用 synthetic fixture；授权用户可在本机私有环境验证真实数据而不向 Public 仓库上传。
4. 所有 relations / events 引用指向已注册节点；未知被明确标识；复跑稳定。
5. PR 通过后再讨论是否采用 adapter 输出驱动前端，禁止直接在 Run 01 做。
