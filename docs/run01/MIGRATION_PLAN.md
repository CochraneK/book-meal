## 协同与权威

- book-meal：书库 manifest、单书身份/入口、面向公众的转换数据规范和 UI。
- AI-persona：Human Ontology / PersonaKernel 唯一语义真源。Book-Meal 仅持版本化引用。
- sanggan：原始文字衍生、内核、事件图及研究备份真源，在审核公开范围之前保持私有。
- Secondme-Framework：证据、竞争解释、长期修订的方法参考；SecondMe 私有记录不得参与批量导入。
- novel2game：游戏流程实现可借鉴；先审查 API 再迁移。
- emperor-skill / ARIS4C：历史研究与论文工作流继续独立。

## 数据迁移安全机制

1. **不改旧 source**：每次输出只读转换、保留 source_id 和 provenance，显式带 contract version。
2. **先双跑**：旧页面继续依赖旧结构，新消费者依赖新结构，同步比较 entity/edge/time/derived UI output。
3. **快照和回退**：保留原始构建产物与 PR base；任何 UI 改动能一键回到之前 main。
4. **质量门禁**：schema 结构检查 + 跨引用检查 + 版权检查 + 合成数据测试 + 真实公开书数据 + 私有授权环境人工校验。
5. **不自动消解冲突**：unknown / orphan / observed vs inferred / 2026-date vs novel-period 全部保留审计标记。
6. **权限隔离**：不把 Private Git 历史移入 Public，不传递 API key，不在 Pages 发布读者无权读取的原文数据。
